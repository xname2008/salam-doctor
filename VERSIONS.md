# Website Version Guide

This folder includes multiple `index` versions so you can roll back quickly.

## Files

- `index-v1.html`
  - First simple landing version.
  - Header + hero only.
- `index-v2.html`
  - Added services section/cards.
  - Cleaner multi-section structure than v1.
- `index-v3.html`
  - Added clinics list, footer, and mobile CTA bar.
  - Mid-stage layout before final polish.
- `index-v4.html`
  - Frozen copy of the latest full version at the time it was created.
  - Includes Swiper integrations and current content structure.
- `index-v5.html`
  - Snapshot after slider/chat and typography updates.
- `index-v6.html`
  - Snapshot with pagination placement fix for testimonial slider.
- `index-v7.html`
  - Snapshot with high-end splash screen (fade-in/scale intro and timed fade-out cleanup).
- `index-v8.html`
  - Snapshot with more premium splash animation (glow pulse, cinematic logo intro/outro).
- `index-v9.html`
  - Snapshot where splash logo stretches during fade-out.
- `index-v10.html`
  - Snapshot with faster splash fade-out and bigger logo growth effect.
- `index-v11.html`
  - Snapshot with heart-shaped splash frame, 3 heartbeat pulses, then expand+fade exit.
- `index-v12.html`
  - Snapshot with larger heart frame and better full-logo fitting inside splash.
- `index-v13.html`
  - Snapshot with full heart shape frame and no edge-cropping on splash logo.
- `index-v14.html`
  - Snapshot fixing duplicate-heart issue and returning to single clean heart frame.
- `index-v15.html`

- `index-v17.html`

- `index-v20.html`
  - Snapshot with runtime white-pixel removal from splash logo (transparent edges).
- `index-v21.html`
  - Reverted snapshot returning from v20 back to v19 state.
- `index.html`
  - Active working file (current editable version).
  - Usually same as the newest snapshot, but may change with future edits.

## Recommended Usage

- Keep editing only `index.html`.
- When you reach a stable milestone, copy it to the next version file (`index-v5.html`, `index-v6.html`, etc.).
- If anything breaks, compare with the nearest previous version and restore quickly.
