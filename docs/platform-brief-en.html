Salam Doctor

Medical referral & clinic directory platform — Shiraz, Iran

May 2026 · Confidential

Salam Doctor (سلام دکتر) is a Persian, RTL web platform that connects patients in Shiraz with vetted clinics and specialists. It combines a searchable clinic directory, consultation lead capture, live chat, and service landing pages — designed for fast deployment, low operating cost, and easy content updates.

What it does

  • Directory of beauty & medical clinics in Shiraz
  • Category browsing (hair, skin, laser, surgery, etc.)
  • Individual clinic profiles with services & contact
  • Consultation request form → stored as leads
  • Real-time chat widget + Bale messenger link
  • Landing pages: home visit, lab, equipment rental

What it is not

  • Not an EMR or hospital information system
  • Not online appointment scheduling (yet)
  • Not payment / insurance processing
  • Not a native mobile app
  • Clinic data is not a dynamic CMS — edited in code

Technology stack

FrontendHTML5, CSS, vanilla JavaScript (no React/Vue). Swiper.js carousels. Local Persian fonts (Vazirmatn, IRANSans).
BackendNode.js (native http), SQLite (better-sqlite3), Socket.IO for live chat.
HostingDocker Compose: Nginx (static + reverse proxy) + Node backend. HTTPS via Let’s Encrypt.
DataClinics in data.js; leads in SQLite leads.db.

Architecture

Visitor → Nginx (443) → Static HTML/CSS/JS
              ↓
         /api/*  → Node.js :3000 → SQLite
         /socket.io/ → In-memory chat sessions
              ↓
         admin.html (Basic Auth) → leads + chat panel

Key pages & APIs

index.htmlcategory.htmlprofile.htmladmin.html

  • POST /api/consultation — save lead (name, phone, service)
  • GET /api/leads — list leads (protected)
  • GET /api/health — uptime check
  • WebSocket /socket.io/ — visitor ↔ admin chat

Business model (typical)

  • Referral / introduction — match patients to partner clinics
  • Lead generation — consultation forms & chat captured centrally
  • Brand trust — curated directory positions Salam Doctor as a local authority
  • Service expansion — home care, lab, equipment rental as additional verticals

Roadmap & growth levers

  • Migrate clinics to a proper database / admin CMS
  • Persist chat history; optional CRM integration
  • SMS / WhatsApp / Bale notifications on new leads
  • Online booking with clinic calendars
  • Reviews & ratings; SEO for each clinic profile
  • Expand beyond Shiraz; partner onboarding portal
