۱. خلاصه مدیریتی

در این بازه، پلتفرم سلام دکتر از یک کاتالوگ نسبتاً استاتیک به یک سامانه ترکیبی پیشرفته‌تر تبدیل شد: بک‌اند Node، ذخیره‌سازی SQLite برای پروفایل کلینیک‌ها، PostgreSQL با Prisma، داکر و Nginx، صفحات سئوی برنامه‌ای (/shiraz/*)، لندینگ خدمات (/services/:slug)، سیستم مقاله/بلاگ، مونتایزیشن دسته‌بندی (تاپ ۱۰ و اسلایدر)، و پروفایل کلینیک + پنل ادمین غنی‌تر.

تمرکز هفته‌های پایانی بیشتر روی کیفیت پروفایل کلینیک نهال (شناسه ۱۱۴)، نقشه، گالری، دپارتمان‌ها، روبیکا/بله، و اصلاح CTAهای صفحه اصلی بوده است.

۲. بک‌اند / API / دیتابیس

دیتابیس و ORM

  • طراحی اسکیمای Prisma + PostgreSQL برای دایرکتوری پزشکی (کلینیک، منطقه، دستگاه، خدمت، قرارداد و …).
  • اعمال و رفع مشکلات مایگریشن‌ها روی سرور (شروع اولیه، مقالات، دپارتمان‌ها، لینک روبیکا/بله).
  • رفع مشکلات اتصال دیتابیس (localhost در برابر host.docker.internal)، دسترسی و هم‌ترازی مایگریشن‌ها.

هسته سرور (server.js)

  • API پروفایل کلینیک: دریافت عمومی و مدیریت در ادمین (ایجاد/ویرایش/حذف).
  • آبجکت contact_info: اینستاگرام، واتساپ، تلگرام، روبیکا، بله، تلفن، آدرس و شماره‌های مشاوره.
  • فیلدهای دپارتمان: عنوان/تلفن/واتساپ بخش اول و دوم + همگام‌سازی با Postgres.
  • فیلدهای روبیکا/بله: عنوان و لینک جداگانه برای هر کدام.
  • مدیریت معرفی ساخت‌یافته کلینیک (فایل clinic-intros) تا ویرایشگر Quill قالب غنی را خراب نکند.
  • پروکسی تایل نقشه برای دسترسی بهتر به OSM در ایران.
  • آپلود تصویر (Multer) برای مقالات و TinyMCE.
  • APIهای سلامت سرویس، سرنخ/مشاوره، ویژه، تبلیغات، تاپ ۱۰ و اسلایدر دسته‌بندی.

سئو و کشف محتوا

  • هاب‌های برنامه‌ای /shiraz/:service_slug با Repository سئو.
  • تزریق متای دینامیک برای پروفایل، دسته و خدمت.
  • تکمیل sitemap.xml (خدمات/برندها و هاب‌ها).
  • بهبود robots.txt و رفتار بات‌ها روی APIهای کلیک (کاهش نویز Search Console).
  • Schema.org: FAQ، بردکرامب، Searchbox سایت، اصلاح خطاهای Review Snippet.
  • پیکربندی کلمات کلیدی دم‌بلند (کاشت مو، لیزر، هایفو و …).
  • داده نمونه/سید برای جلوگیری از صفحات خالی هاب در گوگل.

لندینگ خدمات

  • ماژول serviceLanding.js و مسیر GET /services/:slug (+ API JSON).
  • تطبیق کلینیک‌ها بر اساس اسلاگ خدمت (کاتالوگ + لایه SQLite).
  • فیلتر تگ‌ها: فقط خدمات مرتبط با همان صفحه؛ تگ‌ها غیرقابل‌کلیک.
  • بخش FAQ و جابه‌جایی دکمه «مشاهده مراکز معتبر» به زیر FAQ.

بلاگ / مقالات

  • جدول مقالات در Postgres + CRUD ادمین.
  • TinyMCE و مسیر آپلود تصویر.
  • قالب‌های لیست/پست با تمرکز E-E-A-T.

مونتایزیشن

  • تاپ ۱۰ دسته‌بندی (به‌جای تاپ ۵) + اسلایدر اختصاصی هر دسته.
  • تبلیغات با تصویر جدا برای دسکتاپ و موبایل.
  • گزارش‌گیری مراکز ویژه و بنرها.

۳. فرانت‌اند (صفحات و منطق کلاینت)

صفحه اصلی

  • ریبرند هیرو: «سلام دکتر، همراه سلامتی شما».
  • حذف تاپ ۵/اسلایدر سراسری؛ افزودن بخش «دسته‌بندی‌های برتر» (۶ کاشی).
  • تمرکز CTA روی ثبت کلینیک / پشتیبانی سایت به‌جای مشاوره عمومی.
  • هدر: جایگزینی «ثبت کلینیک» با «پشتیبانی سایت»؛ دکمه «درباره ما» در هیرو.
  • اصلاح اعتبارسنجی شماره تلفن فرم برای پیش‌شماره +۹۸ و ۰۰۹۸.

دسته و لندینگ‌ها

  • صفحه پویای category.html بر اساس پارامتر type.
  • نمایش تاپ ۱۰ و اسلایدر روی صفحات دسته و خدمات.
  • پارک موقت صفحات کم‌اولویت (ویزیت منزل، آزمایشگاه، تجهیزات).

پروفایل کلینیک

  • نام، تلفن، آدرس و خدمات دینامیک از API و کاتالوگ.
  • نوار اکشن زیر تصویر اصلی (تماس، واتساپ، اینستاگرام، مسیر، روبیکا، بله).
  • عناوین دپارتمان‌ها و کاشی‌های مشاوره زیر بخش‌های ۱ و ۲.
  • نقشه Leaflet با OpenStreetMap و پروکسی تایل.
  • گالری‌ها با اسکرول‌اسنپ بومی (RTL و سوایپ موبایل/دسکتاپ).
  • ترجیح HTML ساخت‌یافته ذخیره‌شده در دیتابیس نسبت به فایل استاتیک قدیمی Nginx.
  • حذف پسوند خودکار «در شیراز» از عنوان H1 کلینیک‌ها.
  • فوتر چسبان موبایل: تماس تلفنی و واتساپ خود کلینیک.
  • مسیریابی: گوگل / نشان / بلد + اسنپ.
  • لایت‌باکس تصویر هیرو تمام‌صفحه؛ کلیک روی هر نقطه برای بستن.
  • حذف بنر تبلیغاتی داخل صفحه پروفایل.
  • ماسک نام کلینیک‌های نمونه (به‌جز نهال).

پنل ادمین

  • ویرایش پروفایل: تماس، مختصات، خدمات، دپارتمان‌ها، معرفی.
  • حالت HTML خام برای معرفی ساخت‌یافته (مثل نهال) و Quill برای بقیه.
  • ویرایشگر مقاله TinyMCE + آپلود.
  • مدیریت تاپ ۱۰، اسلایدر و تبلیغات دسته‌بندی.
  • فیلدهای عنوان/لینک روبیکا و بله.

۵. سئو و رشد

  • هاب‌های برنامه‌ای /shiraz/* با overrideهای دم‌بلند.
  • تزریق متا سمت سرور بدون نیاز به موتور قالب کامل.
  • کامل‌کردن سایت‌مپ (خدمات و هاب‌ها).
  • پاکسازی Search Console: URLهای کلیک API، صفحات خالی هاب، ریدایرکت/کنونیکال، خطای اسکیما.
  • بهبود Core Web Vitals: preload فونت/هیرو، lazy تصویر، کش و Gzip در Nginx.
  • Schema جعبه‌جستجوی Sitelinks و بردکرامب.

۶. محتوا و کلینیک نهال

  • قالب معرفی ساخت‌یافته clinic-intros/114.html.
  • حالت HTML در ادمین تا Quill چیدمان غنی را تخت نکند.
  • اتصال رسانه پوشه /clinics/114 (هیرو، لوگو، ویدیو، گالری، قبل/بعد).
  • ماسک نام نمونه‌ها؛ حفظ نام واقعی نهال.
  • اتصال تگ خدمات نهال به لندینگ‌های /services/{slug}.

۷. زیرساخت و DevOps

  • Docker Compose: بک‌اند + Nginx + Certbot.
  • تنظیمات Nginx: فشرده‌سازی، کش، پروکسی API و /services/.
  • مانت ولوم برای فایل‌های حیاتی (از جمله clinic-intros).
  • رفع خطای native ماژول better-sqlite3، خطای ۵۰۲ بعد از دیپلوی، ریلود Nginx داخل داکر.

  • خطاهای GSC روی کلیک featured/ads، صفحات خالی هاب، اسکیما Review.
  • رد شدن شماره تلفن با پیش‌شماره +۹۸ / ۰۰۹۸ در فرم.

۱۱. نکات عملیاتی پیشنهادی برای ادامه کار

  • بعد از هر مایگریشن جدید حتماً npx prisma migrate deploy اجرا شود.
  • بک‌اند را با ولوم clinic-intros دوباره بالا بیاورید تا فایل معرفی و Nginx هم‌خوان بماند.
  • بعد از دیپلوی، ادمین و پروفایل را Hard Refresh کنید.
  • سایت اختصاصی کلینیک‌ها / سیستم نوبت‌دهی در طراحی اولیه آمده ولی فعلاً نسبت به سئو اولویت پایین‌تری داشته است.
  • در برخی صفحات، منوی موبایل هنوز ممکن است لینک قدیمی «ثبت کلینیک و ارتقای جایگاه» را نشان دهد (هدر دسکتاپ صفحه اصلی به‌روز شده است).
