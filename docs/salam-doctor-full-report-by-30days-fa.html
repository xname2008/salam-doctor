۱. خلاصه کل پروژه

پروژه سلام دکتر از یک لندینگ HTML ساده شروع شد و طی حدود سه ماه به یک پلتفرم دایرکتوری کلینیک‌های زیبایی/درمانی شیراز تبدیل شد: صفحه اصلی و پروفایل کلینیک، پنل ادمین، بک‌اند Node، دیتابیس SQLite و PostgreSQL، Docker/Nginx/HTTPS، سئوی برنامه‌ای، لندینگ خدمات برند/دستگاه، مونتایزیشن (تاپ ۱۰ و تبلیغات)، بلاگ، و پروفایل غنی نهال.

دورهتاریخ تقریبیتم اصلی
دوره ۱ ۲ مه تا ۳۱ مه ۲۰۲۶ راه‌اندازی فرانت، طراحی صفحه اصلی، اسلایدر، فونت محلی، چت شناور، شروع امنیت و HTTPS
دوره ۲ ۱ ژوئن تا ۳۰ ژوئن ۲۰۲۶ داده پویا، SQLite/لیدها، مونتایزیشن، ادمین، بکاپ، سئوی پایه، پایداری سرور
دوره ۳ ۱ ژوئیه تا ۲۷ ژوئیه ۲۰۲۶ Prisma/SEO hubs، خدمات دینامیک، بلاگ، پروفایل نهال، نقشه/گالری، دپارتمان، روبیکا/بله

منبع: تاریخچه گفت‌وگوهای Cursor روی همین پروژه. تاریخ‌ها تقریبی‌اند (برخی پیام‌ها بدون timestamp بوده‌اند و بر اساس ترتیب کار به دوره مرتبط نسبت داده شده‌اند).

۲. دوره ۱ — روز ۱ تا ۳۰

۲ مه – ۳۱ مه ۲۰۲۶

هدف دوره: ساخت اسکلت سایت، ظاهر حرفه‌ای، تجربه موبایل، و آماده‌سازی انتشار آنلاین اولیه.

فرانت‌اند

  • ایجاد پروژه و فایل اولیه index.html.
  • بخش‌های هیرو، خدمات، معرفی مراکز، نظرات، فوتر و ناوبری موبایل پایین صفحه.
  • الهام از سایت‌های مشابه شیراز و ساخت لندینگ کامل.
  • تبدیل بخش پزشکان/نظرات به اسلایدر؛ نسخه‌گذاری فایل‌های index.
  • شروع اتصال داده از data.js برای بخش کلینیک‌ها.
  • ایجاد صفحات پایه مثل پروفایل/دسته در ادامه همین خط کار.

UI / UX

  • چیدمان ریسپانسیو (موبایل / تبلت / دسکتاپ) و رفع به‌هم‌ریختگی کاشی‌ها.
  • اسپلش‌اسکرین لوگو با انیمیشن ضربان قلب و محو شدن.
  • ویجت چت شناور سفارشی (جایگزین Gapify).
  • فونت محلی IRANSans و حذف وابستگی به CDN فونت.
  • رفع مشکلات نمایش اسلایدر روی Windows/Chrome و iPad.
  • تصاویر محلی به‌جای وابستگی به اینترنت.

بک‌اند / امنیت اولیه

  • شروع محافظت API لیدها با Basic Auth در Nginx.
  • آماده‌سازی مسیر لیدها و جلوگیری از دسترسی عمومی به داده‌های مشتری.

DevOps / زیرساخت

  • راه‌اندازی HTTPS با Let's Encrypt برای salam-doctor.ir.
  • تغییر تمدید گواهی از standalone به webroot (بدون قطع سرویس).
  • زمان‌بندی cron برای renew گواهی و ریلود Nginx.
  • ایجاد robots.txt اولیه (اجازه خزش + بلاک ادمین/لیدها).

سئو (شروع)

  • آماده‌سازی robots و پایه ایندکس‌پذیری صفحات عمومی.
  • استخراج CSS/فونت مشترک برای کاهش تکرار و بهبود نگهداری صفحات.

خروجی دوره ۱: یک لندینگ قابل انتشار با ظاهر برند، فونت محلی، چت، و زیرساخت HTTPS.

۳. دوره ۲ — روز ۳۱ تا ۶۰

۱ ژوئن – ۳۰ ژوئن ۲۰۲۶

هدف دوره: تبدیل سایت استاتیک به سامانه واقعی با داده، درآمدزایی، ادمین، بکاپ و پایداری سرور.

بک‌اند

  • انتقال لیدها از JSON به SQLite (leads.db) برای جلوگیری از فساد داده.
  • APIهای مونتایزیشن: جایگاه ویژه کلینیک‌ها، تبلیغات چرخشی، ردیابی کلیک/درآمد.
  • شروع CMS مقاله روی SQLite + رندر سمت سرور.
  • چت لحظه‌ای Intranet با Socket.IO بین کاربر و ادمین.
  • حذف URLهای هاردکد localhost:3000 برای کار روی سرور واقعی.

فرانت‌اند

  • منوهای واقعی به‌جای href="#" برای ایندکس گوگل و ناوبری.
  • UI کاربر و ادمین برای تاپ کلینیک‌ها و بنر تبلیغاتی.
  • تب مدیریت مقالات در ادمین با ادیتور WYSIWYG و آپلود تصویر.
  • صفحه لیست مقالات و رندر عمومی مقاله.
  • بهبود فرم مشاوره و تبدیل ارقام فارسی/انگلیسی.
  • Dropdown منوی خدمات در هدر و همگام‌سازی پروفایل/دسته.

UI / UX

  • کوتاه‌کردن زمان اسپلش و نمایش فقط یک‌بار در هر نشست (sessionStorage).
  • طبیعی‌سازی نظرات کاربران (آواتار و امتیاز واقعی‌تر).
  • مرتب‌سازی عناصر شناور موبایل (بله / چت / ناوبری پایین) برای جلوگیری از هم‌پوشانی.
  • لوگوی هدر و فاویکون حرفه‌ای.
  • اختصاص تصویر به اسلایدها و پروفایل‌ها بر اساس نام کلینیک.

سئو

  • عنوان دینامیک برای category/profile.
  • Open Graph و Structured Data اولیه برای پیش‌نمایش شبکه‌های اجتماعی و ریچ‌ریزالت.
  • بهبود sitemap و آمادگی Search Console.
  • بهینه‌سازی سرعت بارگذاری صفحات اصلی.

DevOps / امنیت / عملیات

  • Basic Auth برای admin.html با htpasswd.
  • اسکریپت بکاپ محلی و آف‌سایت برای leads.db.
  • رفع داون‌تایم بعد از تغییرات Nginx/Compose و بازیابی اضطراری.
  • تثبیت ارتباط ادمین با بک‌اند داخل Docker.

سایر (خارج از وب اصلی)

  • شروع اپ اندروید Contact Shield (مسدودسازی تماس/لاگ) به‌عنوان کار جانبی.

خروجی دوره ۲: سایت آنلاین پایدارتر با درآمدزایی اولیه، ادمین عملیاتی، بکاپ، و پایه سئو.

۴. دوره ۳ — روز ۶۱ تا ۸۷

۱ ژوئیه – ۲۷ ژوئیه ۲۰۲۶

هدف دوره: رشد سئوی برنامه‌ای، زیرساخت دیتابیس حرفه‌ای، پروفایل کلینیک سطح بالا (نهال)، و تکمیل مسیر درآمد/محتوا.

بک‌اند

  • طراحی کامل اسکیمای Prisma/PostgreSQL برای دایرکتوری پزشکی.
  • DirectoryRepository و هاب‌های دینامیک /shiraz/:service_slug.
  • لندینگ خدمات برند/دستگاه: /services/:slug (DEKA، CANDELA، Fotona، FIT و …).
  • مدل contact_info و فیلدهای دپارتمان (عنوان/تلفن/واتساپ).
  • فیلدهای روبیکا/بله: عنوان + لینک؛ همگام‌سازی با Postgres.
  • معرفی ساخت‌یافته کلینیک (clinic-intros) و جلوگیری از خراب شدن قالب توسط Quill.
  • پروکسی تایل نقشه برای دسترسی بهتر OSM در ایران.
  • سیستم مقالات روی Postgres + TinyMCE + آپلود.
  • تاپ ۱۰ دسته‌بندی، اسلایدر اختصاصی، تبلیغات دسکتاپ/موبایل.
  • رفع باگ‌های ذخیره ادمین نهال (۵۰۰ و «ذخیره بدون تغییر ظاهری»).

فرانت‌اند

  • بازطراحی صفحه اصلی: حذف اسلایدر سراسری، افزودن ۶ کاشی Top Categories.
  • انتقال تاپ کلینیک/اسلایدر به صفحات دسته و لندینگ خدمات.
  • پروفایل کلینیک کاملاً دینامیک (تلفن، آدرس، خدمات لینک‌دار، اکشن‌بار).
  • گالری‌های قبل/بعد و تصاویر با سوایپ RTL.
  • نقشه Leaflet + مسیریابی گوگل/نشان/بلد/اسنپ.
  • کاشی‌های مشاوره واتساپ/تلفن زیر بخش‌های ۱ و ۲ معرفی.
  • فوتر موبایل پروفایل: تماس و واتساپ خود کلینیک.
  • لندینگ خدمت با FAQ و دکمه «مشاهده مراکز معتبر» زیر FAQ.
  • ماسک نام کلینیک‌های نمونه (به‌جز نهال).

UI / UX

  • هیرو برند: «سلام دکتر، همراه سلامتی شما».
  • CTA هدر: «پشتیبانی سایت»؛ افزودن «درباره ما» در هیرو.
  • کاشی‌های رنگی/تصویری دسته‌بندی روی صفحه اصلی.
  • اکشن‌بار زیر تصویر هیرو با رنگ برند (تماس، واتساپ، اینستا، مسیر، روبیکا، بله).
  • لایت‌باکس تمام‌صفحه برای تصویر اصلی (رفع قرارگیری زیر فوتر).
  • حذف بنر تبلیغاتی داخل پروفایل؛ حذف پسوند «در شیراز» از عنوان کلینیک‌ها.
  • استانداردسازی کانتینر تصویر/ویدیو و نسبت تصویر هیرو.

سئو و رشد

  • زیرساخت سئوی دینامیک: Title/Description/Canonical/JSON-LD.
  • تکمیل sitemap برای هاب‌ها و صفحات خدمت/برند.
  • رفع مشکلات GSC: redirect، صفحه خالی هاب، خطای 5xx روی API کلیک، اسکیما Review.
  • Searchbox Schema و Breadcrumb Schema.
  • کلمات کلیدی دم‌بلند شیراز (کاشت مو اقساطی، کندلا، هایفو و …).
  • بهبود Core Web Vitals: preload، lazy، کش/Gzip Nginx.

DevOps

  • استراتژی Docker Compose + Nginx برای روتینگ و سایت اختصاصی کلینیک‌ها.
  • رفع اتصال Prisma به دیتابیس (localhost در برابر host.docker.internal).
  • مانت ولوم‌های حیاتی (از جمله clinic-intros).
  • رفع 502، unhealthy بودن بک‌اند، و rebuild ماژول native sqlite.

محتوا / محصول / کلینیک نهال

  • اتصال کامل رسانه نهال از پوشه clinics/114.
  • قالب معرفی ساخت‌یافته HTML برای نهال.
  • ادیت ادمین برای عناوین دپارتمان و پیام‌رسان‌ها.
  • تبدیل مسیر محصول از «مشاوره عمومی» به «ثبت کلینیک / پشتیبانی سایت».

خروجی دوره ۳: پلتفرم آماده رشد گوگل + پروفایل کلینیک قابل فروش/ویرایش + مسیر درآمد و محتوا.

۶. نکات عملیاتی و ادامه کار

  • بعد از هر مایگریشن: npx prisma migrate deploy و در صورت نیاز npx prisma generate.
  • بعد از تغییر بک‌اند: ریستارت/ری‌کرییت کانتینر و Hard Refresh مرورگر.
  • ولوم clinic-intros باید بین بک‌اند و فایل‌های استاتیک Nginx همگام باشد.
  • اولویت اولیه سئو بود؛ نوبت‌دهی آنلاین و سایت اختصاصی کلینیک‌ها در نقشه راه بعدی است.
  • برای ارائه به تیم: همین فایل را با دکمه چاپ به PDF تبدیل کنید.
